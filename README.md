四大鹽業巨頭寡占競賽：





Compass Minerals（玩家）：擁有加拿大 Goderich 礦場 100 呎厚鹽層（對手僅 25 呎）之開採與五大湖水運成本優勢。



Cargill Salt（嘉吉鹽業）：跨國大宗商品巨頭，重視規模經濟與市佔平衡。



Morton Salt（莫頓鹽業）：百年品牌，主打消費與食用鹽品牌溢價，道路鹽偏高價防守。



American Rock Salt：紐約新興激進岩鹽礦商，常發動割喉價格戰搶標。



真實外生隨機變數（冬季氣候震盪）：





鹽是高度依賴天氣的季節性大宗商品。系統每回合自動模擬常態分佈之冬季嚴寒指數（0.65x 暖冬少雪 ~ 1.55x 霸王寒流暴風雪），動態影響全美 1,800 萬噸道路除冰鹽的招標總需求。



道路融雪鹽滲入地下水導致的「淡水鹽鹼化危機」。若大西洋水系氯化物濃度突破 160 mg/L 警戒線，政府將強制頒布減鹽環保法規。
可透過投資綠色融雪劑研發與地下鹽穴存檔（Salt Caverns Storage）多角化避險。
